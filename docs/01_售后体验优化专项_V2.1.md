# 售后体验优化专项 V2.1
**版本号**: V2.1 | **更新时间**: 2023-08-15 | **作者**: 产品部-张三

## 核心业务规则
- **触发门槛**：用户信用等级为 `VIP` 或 `SVIP`，且单笔订单实付金额 `< 500元`。
- **状态流转**：`WAIT_AUDIT` -> `RISK_PASS` -> `AUTO_REFUND_SUCCESS`。

## 边界条件
- **超时降级**：若调用支付网关超时（>3000ms），状态需回退至 `WAIT_AUDIT`。

## 关联系统
涉及 `OrderCoreService` 和 `PaymentGatewayClient`。
