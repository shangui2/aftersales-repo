# 售后体验优化专项 V2.1
**文档编号**: PRD-AS-2023-042
**版本号**: V2.1 | **更新时间**: 2023-08-15 | **作者**: 产品部-张三

## 1. 业务背景与目标
为解决高净值用户退款链路过长导致的客诉问题，在一期（V1.0）基础上进行底层重构。目标是将符合条件的退款时效从T+1缩短至秒级到账。

## 2. 核心业务规则
- **触发门槛**：用户信用等级为 `VIP` 或 `SVIP`，且单笔订单实付金额 `< 500元`。
- **处理逻辑**：用户在前端发起退款申请时，跳过商家审核节点，由风控引擎校验后，直接调用支付网关原路退回资金。
- **状态流转**：订单售后状态机新增流转路径：`WAIT_AUDIT` -> `RISK_PASS` -> `AUTO_REFUND_SUCCESS`。

## 3. 边界条件与异常处理
- **超时降级**：若调用支付网关超时（>3000ms），状态需回退至 `WAIT_AUDIT`，并生成工单转交人工处理。
- **优惠券抵扣**：使用优惠券抵扣的部分不退现金，仅退还对应面额的优惠券至用户账户。

## 4. 关联系统与依赖
- 强依赖：`OrderCoreService` (订单核心服务), `PaymentGatewayClient` (支付网关)
