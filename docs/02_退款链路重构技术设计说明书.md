# 退款链路重构技术设计说明书
**版本号**: V1.0 | **更新时间**: 2022-11-10 | **作者**: 研发部-李四

## 1. 概述
本文档描述快速退款的底层实现方案。

## 2. 核心类设计
- 新增枚举类 `RefundTypeEnum`，包含 `NORMAL` 和 `FAST_REFUND`。
- 核心处理类为 `FastRefundProcessor`，继承自 `BaseRefundHandler`。

## 3. 业务规则说明（注意：此处与V2文档有冲突）
- 自动退款金额上限设定为 `1000元`（注：后被V2版本修改为500元）。
- 所有用户均可享受，无需校验VIP等级（注：后被V2版本增加限制）。

## 4. 数据库变更
在 `t_order_refund` 表中增加字段 `is_fast_refund` (tinyint)。
