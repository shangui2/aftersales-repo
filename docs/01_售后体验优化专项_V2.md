# 售后体验优化专项 V2
**版本号**: V2.1 | **更新时间**: 2023-06-15 | **作者**: 产品部-张三

## 1. 业务背景
为了提升VIP用户的售后体验，缩短退款到账时间，我们在一期基础上进行了流程重构。

## 2. 核心业务规则
- **触发条件**：用户信用等级为 `VIP` 且 订单金额 `< 500元`。
- **处理逻辑**：当用户发起退款申请时，系统不再等待商家审核，直接调用底层接口将资金原路退回。
- **状态流转**：订单售后状态直接从 `WAIT_AUDIT` 变更为 `AUTO_REFUND_SUCCESS`。

## 3. 边界条件与异常处理
- 如果调用支付网关超时，状态需回退至 `WAIT_AUDIT`，转交人工处理。
- 优惠券抵扣部分不退现金，仅退还优惠券。

## 4. 关联系统
涉及 `OrderService` 和 `PaymentGatewayClient`。
