# 退款链路底层重构技术设计说明书
**文档编号**: TECH-AS-2022-019
**版本号**: V1.0 | **更新时间**: 2022-11-10 | **作者**: 研发部-李四

## 1. 概述
本文档描述快速退款底层的实现方案及数据库变更。

## 2. 核心类与接口设计
- 新增枚举类 `RefundTypeEnum`，包含 `NORMAL` 和 `FAST_REFUND`。
- 核心处理类为 `FastRefundProcessor`，继承自抽象类 `BaseRefundHandler`。

## 3. 业务规则说明（⚠️注意：此部分规则已被V2.1版本覆盖）
- 自动退款金额上限设定为 `1000元`。
- 面向全量用户开放，无需校验VIP等级。

## 4. 数据库变更 (DDL)
在 `t_order_refund_record` 表中增加字段：
- `is_fast_refund` (tinyint)
- `legacy_channel_code` (varchar): 早期渠道标识（注：该字段在后续迭代中疑似废弃）
